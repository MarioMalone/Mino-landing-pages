# Mino Landing Page

Product landing page for [Mino](https://github.com/mario-lou/8.Mino), a lightweight Markdown WYSIWYG editor for Windows.

## Tech Stack

- Pure HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript

## Development

Open `index.html` in a browser — no build step required.

## Structure

```
├── index.html        # Main page
├── css/style.css     # Custom styles
├── js/main.js        # Interaction logic
├── assets/           # Images, icons
└── favicon.ico       # Site favicon
```
